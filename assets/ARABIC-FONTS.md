# Arabic typefaces

Locally hosted official Google Fonts files, downloaded for the Arabic preview.

- Amiri Regular: https://github.com/google/fonts/tree/main/ofl/amiri — `amiri-regular.ttf`, licence `Amiri-OFL.txt`.
- Noto Sans Arabic variable: https://github.com/google/fonts/tree/main/ofl/notosansarabic — `noto-sans-arabic.ttf`, licence `NotoSansArabic-OFL.txt`.

Both use the SIL Open Font License. Arabic headings preserve the editorial character of the English design; Arabic body text uses Noto Sans Arabic for legibility. No external font requests are required.
